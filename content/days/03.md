# Day 3: 给 AI 发消息

## 这一节要解决什么问题？

让代码真正和 AI 对话。就像你打开网页给朋友发消息，代码也需要"发消息"给 AI。只是格式不同——用的是 **JSON**。

## 什么是 HTTP 请求？

网络请求就像写信：
- **URL** = 收件地址（AI 的接口地址）
- **Method** = 寄信方式（POST = 发送数据）
- **Headers** = 信封信息（身份认证）
- **Body** = 信的内容（发给 AI 的指令）

## 代码演示

```js
// 给 Claude API 发消息
async function 发消息给AI(你的问题) {
  const response = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": process.env.ANTHROPIC_API_KEY,
      "anthropic-version": "2023-06-01",
      "anthropic-dangerous-direct-browser-access": "true",
    },
    body: JSON.stringify({
      model: "claude-sonnet-4-7-20250514",
      max_tokens: 1024,
      messages: [{ role: "user", content: 你的问题 }],
    }),
  });

  const data = await response.json();
  return data.content[0].text;
}

// 测试（需要设置 ANTHROPIC_API_KEY 环境变量）
(async () => {
  console.log("正在问 AI...");
  const 回复 = await 发消息给AI("你好，请用一句话介绍你自己");
  console.log("AI 回复:", 回复);
})();
```

## 知识点

- `fetch(url, options)` — 浏览器和 Node.js 内置的 HTTP 请求工具
- `JSON.stringify()` — 把 JS 对象转成 JSON 字符串
- `response.json()` — 把服务器返回的 JSON 字符串解析成 JS 对象
- `process.env.ANTHROPIC_API_KEY` — 从环境变量读取 API Key（安全）
