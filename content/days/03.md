# Day 3: 给 AI 发消息

## 这一节要解决什么问题？

让代码真正和 AI 对话。就像你打开网页给朋友发消息，代码也需要"发消息"给 AI。只是格式不同——用的是 **JSON**。本节要解决的核心问题是：如何让你的程序通过网络，把一段文字发给 AI 模型，然后收到它的回复？

理解这个过程的关键是**HTTP 协议**。HTTP 是互联网的"邮政系统"：不管你用的是浏览器、Python 代码还是 Node.js，只要在网络上传输数据，都遵循同一套规则——请求是什么地址、用的什么方法、内容是什么格式。这套规则如此成功，以至于 30 年后的今天，AI API 仍然用它来通信。

更进一步，Claude Code 的所有能力都建立在这个基础上：给 AI 发消息（HTTP POST）、让 AI 调用工具（AI 返回 tool_use 指令，程序执行后再通过 HTTP 传回结果）、处理流式输出……**掌握 HTTP 请求，就等于掌握了 AI Agent 通信的底层原理**。无论你将来用 Python 的 `requests`、JavaScript 的 `fetch`，还是直接用 SDK，理解背后的 HTTP 交互都能帮你调试问题。

## 基础知识

### 1. HTTP 请求的四个组成部分

一个完整的 HTTP 请求由四部分组成：URL（地址）、Method（方法）、Headers（请求头）、Body（请求体）。对于 AI API 来说，最常用的是 `POST` 方法——因为我们要"发送"数据给 AI，而不是"获取"网页。

```js
// 用 fetch 发送一个完整的 HTTP POST 请求
const response = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",                          // 方法：POST = 发送数据
  headers: {
    "Content-Type": "application/json",    // 告诉服务器：body 是 JSON 格式
    "x-api-key": "sk-ant-...",             // 身份认证凭证
    "anthropic-version": "2023-06-01",      // API 版本（Anthropic 要求必须带）
    "anthropic-dangerous-direct-browser-access": "true", // 浏览器直连标识
  },
  body: JSON.stringify({                   // 把 JS 对象序列化成 JSON 字符串
    model: "claude-sonnet-4-7-20250514",   // 模型名称
    max_tokens: 1024,                      // 最大输出 token 数
    messages: [
      { role: "user", content: "你好" }    // 对话消息数组
    ],
  }),
});
```

### 2. JSON：数据交换的语言

JSON（JavaScript Object Notation）是互联网上最通用的数据格式。AI API 用 JSON 收发数据，是因为它简单、可读性好、几乎所有编程语言都能解析。JSON 的核心规则：
- 对象用 `{}`，数组用 `[]`
- 键必须用**双引号**（与 JS 对象字面量不同）
- 值可以是字符串、数字、布尔、null、对象或数组

```js
// JS 对象 → JSON 字符串（发送时）
const obj = { name: "Claude", age: 3 };
const json = JSON.stringify(obj);
console.log(json); // '{"name":"Claude","age":3}'

// JSON 字符串 → JS 对象（收到时）
const data = JSON.parse(json);
console.log(data.name); // "Claude"

// 常见错误：把对象直接当字符串发给 API（不会自动序列化）
// 错误写法：body: { ... }           ← fetch 不会自动 JSON.stringify
// 正确写法：body: JSON.stringify({ ... })
```

### 3. Anthropic API 的特殊字段

Anthropic 的 `/v1/messages` 接口有几个容易遗漏的必填项：

- `anthropic-version`：必须设为 `2023-06-01`，告诉服务器使用哪个版本的 API 协议
- `anthropic-dangerous-direct-browser-access`：如果从浏览器直接调用（而非通过后端代理），必须设为 `true`
- `messages` 数组：必须以 `user` 消息开头，不能以 `assistant` 消息开头（这是 Anthropic 与 OpenAI 格式的显著差异）

## 进阶知识

### 流式响应：实时看到 AI "打字"

默认情况下，API 要等 AI 完全生成完整回复后才返回（要等几秒钟）。但 Claude 支持 **SSE（Server-Sent Events）** 流式输出，让你实时看到 AI 一个字一个字地输出：

```js
// 流式请求：需要把 stream: true 加入请求
const response = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-api-key": "sk-ant-...",
    "anthropic-version": "2023-06-01",
    "anthropic-dangerous-direct-browser-access": "true",
  },
  body: JSON.stringify({
    model: "claude-sonnet-4-7-20250514",
    max_tokens: 1024,
    messages: [{ role: "user", content: "写一首诗" }],
    stream: true,  // ← 开启流式输出
  }),
});

// response.body 是一个 ReadableStream，需要用流式 API 读取
const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  // value 是 Uint8Array，每收到一个数据块就解码并打印
  const text = decoder.decode(value);
  process.stdout.write(text);
}
```

### 错误重试：429 Too Many Requests 的处理

AI API 有速率限制（Rate Limit）。收到 429 时，应该等待一段时间后重试：

```js
async function 带重试的请求(url, options, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    const response = await fetch(url, options);
    if (response.status === 429) {
      // 429：等待一段时间后重试，等待时间指数增长
      const waitMs = (attempt + 1) * 1000; // 1秒，2秒，3秒
      console.log(`触发限流，等待 ${waitMs}ms 后重试...`);
      await new Promise(r => setTimeout(r, waitMs));
      continue;
    }
    return response;
  }
  throw new Error(`重试 ${maxRetries} 次后仍然失败`);
}
```

## 代码演示

```js
// 给 Claude API 发消息
async function 发消息给AI(你的问题) {
  const response = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": process.env.ANTHROPIC_API_KEY,
      "anthropic-version": "2023-06-01",
      "anthropic-dangerous-direct-browser-access": "true",
    },
    body: JSON.stringify({
      model: "claude-sonnet-4-7-20250514",
      max_tokens: 1024,
      messages: [{ role: "user", content: 你的问题 }],
    }),
  });

  const data = await response.json();
  return data.content[0].text;
}

// 测试（需要设置 ANTHROPIC_API_KEY 环境变量）
(async () => {
  console.log("正在问 AI...");
  const 回复 = await 发消息给AI("你好，请用一句话介绍你自己");
  console.log("AI 回复:", 回复);
})();
```

## 知识点速查表

| 概念 | 说明 | 示例 |
|------|------|------|
| HTTP POST | 向服务器发送数据的请求方法 | `fetch(url, { method: "POST" })` |
| Headers | 请求的元信息，描述请求本身 | `"Content-Type": "application/json"` |
| Body | 请求的主体内容（JSON 格式） | `body: JSON.stringify({ ... })` |
| JSON.stringify | JS 对象 → JSON 字符串 | `JSON.stringify({ a: 1 })` → `'{"a":1}'` |
| JSON.parse | JSON 字符串 → JS 对象 | `JSON.parse('{"a":1}')` → `{ a: 1 }` |
| response.json() | 解析 JSON 响应体（fetch 封装） | `const data = await res.json()` |
| response.ok | HTTP 状态码是否在 200-299 范围 | `if (!res.ok) throw new Error(...)` |
| stream: true | 开启流式输出，实时收到数据块 | Anthropic/ OpenAI 都支持 |
| 环境变量 | 安全存储 API Key 的方式 | `process.env.ANTHROPIC_API_KEY` |
