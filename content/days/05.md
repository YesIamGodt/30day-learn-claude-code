# Day 5: 第一个工具：让 AI 执行命令

## 这一节要解决什么问题？

AI 能回答问题，但**不能做事**。给它加一个 Bash 工具，它就能真正执行命令了——跑脚本、安装依赖、git 操作，统统都能做。

## 代码演示

```js
const { spawn } = require("child_process");

class BashTool {
  get name() { return "bash"; }
  get description() { return "在终端执行命令，返回输出结果"; }

  async execute(command) {
    return new Promise((resolve, reject) => {
      const [cmd, ...args] = command.split(" ");
      const proc = spawn(cmd, args, { shell: true });

      let stdout = "";
      let stderr = "";

      proc.stdout.on("data", data => { stdout += data.toString(); });
      proc.stderr.on("data", data => { stderr += data.toString(); });

      proc.on("close", code => {
        if (code === 0) {
          resolve(stdout.trim() || "(无输出)");
        } else {
          reject(new Error(`命令失败 (${code}): ${stderr.trim()}`));
        }
      });

      proc.on("error", reject);
    });
  }
}

// 测试
(async () => {
  const tool = new BashTool();
  try {
    const result = await tool.execute("echo 'Hello from bash!'");
    console.log("命令输出:", result);
  } catch (e) {
    console.error("执行失败:", e.message);
  }
})();
```

## 知识点

- `child_process.spawn()` — Node.js 执行系统命令
- `shell: true` — 在 shell 中执行，支持管道等复杂命令
- `process.on("data")` — 监听命令输出流
- `process.on("close", code)` — 命令执行完毕，获取退出码
