      ## Textual — 现代 Python TUI 框架

      JS Demo 用纯 JavaScript 模拟了 TUI 的渲染逻辑（添加分隔线、消息气泡、页脚工具栏），而 Python 源码展示的是用 **Textual** 这个真实框架构建的完整可运行的 TUI 应用。

      ### 为什么 Claude Code 需要 TUI？

      Claude Code 默认通过命令行交互（stdin/stdout），界面简陋。TUI 可以带来更好的用户体验：

      - **彩色输出**：用 ANSI 转义序列给文字着色
      - **布局控制**：不像普通 print 那样顺序输出，可以做多栏布局
      - **实时更新**：不需要等命令结束再显示结果
      - **键盘快捷键**：替代鼠标操作，提升效率

      ### Textual 的核心概念

      Textual 受 Web 前端开发的启发，引入了**声明式 UI**的概念：

      1. **Widget（部件）**：UI 的基本单元，如 `Header`、`Footer`、`Log`、`Input`
      2. **App（应用）**：顶级容器，管理所有 Widget 的生命周期
      3. **CSS**：用类 CSS 语法定义样式（颜色、边框、内边距）
      4. **Bindings**：键盘快捷键绑定到具体动作
      5. **compose()**：声明式地组合 UI 组件（类似 React 的 JSX）

# Day 28: 炫酷界面 Textual

## 这一节要解决什么问题？

Claude Code 默认是黑白文字的终端。给它做一个漂亮的 TUI（终端用户界面）——彩色、动画、布局优雅。

## Textual 是什么？

Textual 是 Python 的 TUI 框架，可以做出这样的界面：

```
┌──────────────────────────────────┐
│  Claude Code           [Day 15] │
├──────────────────────────────────┤
│                                  │
│  🟢 你: 帮我写个快速排序          │
│                                  │
│  🔵 Claude: 当然！这是 Python     │
│          版本的快速排序...         │
│                                  │
├──────────────────────────────────┤
│  [Bash] [Files] [Web]  Tokens: 1k│
└──────────────────────────────────┘
```

## 知识进阶：TUI vs GUI vs Web

| 类型 | 优势 | 劣势 | 适用场景 |
|------|------|------|---------|
| **TUI** | 零依赖、SSH 可用、键盘操作 | 表达能力有限 | 开发者工具、服务器管理 |
| **GUI** | 图形丰富、鼠标交互 | 跨平台成本高 | 桌面应用 |
| **Web** | 最强表现力、响应式 | 需要浏览器 | 需要丰富交互的产品 |

TUI 在**开发者工具**领域有独特价值：不需要图形环境，远程服务器上也能用，资源占用极低。

### Python 真实源码解析

```python
# tui.py — Textual TUI 界面实现

from textual.app import App, ComposeResult
from textual.widgets import Header, Footer, Log, Input
from textual.containers import Container
from textual.binding import Binding

class ClaudeTUI(App):
    """
    Claude Code 的 Textual TUI 界面。
    Textual 采用声明式 UI：定义 compose() 方法声明界面结构，
    事件处理方法（on_*）处理用户交互。
    """

    # CSS 样式：用类 CSS 语法定义各部件的样式
    CSS = """
    Screen { background: #1e1e2e; }           /* Catppuccin Mocha 深色背景 */
    Log { height: 1fr; border: solid green; } /* 日志区占满剩余空间，带绿色边框 */
    Input { dock: bottom; height: 3; }        /* 输入框固定在底部，高度 3 行 */
    """

    # 键盘快捷键绑定：按键 → (动作方法, 描述, 是否显示)
    BINDINGS = [
        Binding("ctrl+c", "quit", "退出", show=True),
        Binding("ctrl+l", "clear", "清屏", show=True),
    ]

    # compose()：声明式地组合界面部件（类似 React）
    def compose(self) -> ComposeResult:
        yield Header()                       /* 顶部标题栏 */
        yield Container(Log(id="log"))       /* 主内容区：日志/消息显示 */
        yield Footer()                       /* 底部状态栏 */
        yield Input(placeholder="输入消息，按 Enter 发送...", id="input")

    # on_mount()：界面挂载时调用，做初始化
    def on_mount(self):
        log = self.query_one("#log", Log)   /* 通过 CSS ID 获取部件 */
        log.write_line("Claude Code TUI 启动！")
        log.write_line("=" * 40)

    # on_input_submitted()：用户提交输入时调用
    def on_input_submitted(self, event: Input.Submitted):
        log = self.query_one("#log", Log)
        # 渲染用户消息（青色加粗）
        log.write_line(f"[bold cyan]你:[/bold cyan] {event.value}")
        # 渲染 AI 回复（绿色加粗）
        log.write_line(f"[bold green]Claude:[/bold green] [模拟回复] {event.value}")
        # 清空输入框
        self.query_one("#input", Input).value = ""

    # action_clear()：绑定到 Ctrl+L 清屏
    def action_clear(self):
        self.query_one("#log", Log).clear()
```

## 代码演示

```js
// 模拟 Textual 风格的 TUI 组件
class TUIComponent {
  constructor(name) {
    this.name = name;
    this.children = [];
    this.styles = {};
  }

  mount(parent) {
    parent?.children.push(this);
    return this;
  }

  render() {
    return `[${this.name}]`;
  }
}

class TUI {
  constructor() {
    this.root = new TUIComponent("root");
    this.output = [];
  }

  addLine(text, style = "") {
    this.output.push({ text, style });
  }

  divider(char = "─", width = 40) {
    this.addLine(char.repeat(width));
  }

  header(title) {
    this.divider("═");
    this.addLine(`  ${title}`);
    this.divider("═");
  }

  message(role, content) {
    const icon = role === "user" ? "🟢" : "🔵";
    const prefix = role === "user" ? "你" : "Claude";
    this.addLine(`${icon} ${prefix}: ${content}`);
  }

  footer(tools, tokens) {
    this.divider();
    this.addLine(`  [${tools.join("] [")}]   Tokens: ${tokens}`);
  }

  render() {
    return this.output.map(l => l.text).join("\n");
  }
}

// 测试
const ui = new TUI();
ui.header("Claude Code");
ui.message("user", "帮我写个快速排序");
ui.message("assistant", "当然！这是 Python 版本的快速排序。");
ui.footer(["Bash", "Files", "Web", "Search"], "1,234");
ui.divider("─", 40);

console.log(ui.render());
```

## 面试与延伸问题

1. **ANSI 转义序列是什么？** ANSI 是终端控制码的标准，`\x1b[31m` 表示将后续文字设为红色，`\x1b[0m` 表示重置。Textual 底层就是通过 ANSI 序列实现彩色的。现代终端（iTerm2、Windows Terminal、Alacritty）都支持 ANSI。
2. **Textual 和 `curses` 库的区别是什么？** `curses` 是 Python 标准库，API 较底层（处理坐标、窗口刷新）；Textual 在 curses 基础上提供了声明式 UI、CSS 样式、响应式绑定等高级抽象，开发效率高得多。
3. **TUI 如何处理窗口大小变化？** Textual 自动监听 SIGWINCH 信号（窗口大小改变），触发重新布局。对于 curses，需要手动调用 `signal.signal(signal.SIGWINCH, handler)` 注册处理函数。
4. **如何给 TUI 添加动画效果？** Textual 内置了过渡动画（Transition）系统，可以在部件挂载、卸载或属性变化时触发动画，例如 `log.run_widget_updates(transition=Transition(slide, 200))`。
