# Day 19: 历史压缩：太长了怎么办？

## 这一节要解决什么问题？

对话越来越长，历史占满了上下文窗口，但很多早期对话已经不重要了。**上下文压缩**：把旧的冗长历史变成简洁摘要，腾出空间。

## 压缩策略

| 策略 | 适用场景 | 保留内容 |
|------|---------|---------|
| 直接截断 | 简单任务 | 最新 N 条 |
| 摘要压缩 | 复杂对话 | 关键信息 |
| 分层压缩 | 超长对话 | 按重要度分层 |

## 代码演示

```js
class ContextCompactor {
  constructor(maxTokens = 8000) {
    this.maxTokens = maxTokens;
  }

  估算Token(text) {
    const 英文 = text.split(/\s+/).length;
    const 中文 = (text.match(/[\u4e00-\u9fa5]/g) || []).length;
    return Math.ceil(英文 * 1.3 + 中文);
  }

  // 策略1：直接截断（保留系统提示 + 最新消息）
  truncateToLimit(messages, maxMessages = 10) {
    const 系统 = messages.filter(m => m.role === "system");
    const 其他 = messages.filter(m => m.role !== "system");
    return [...系统, ...其他.slice(-maxMessages)];
  }

  // 策略2：生成摘要（模拟）
  summarize(messages) {
    const userMsgs = messages.filter(m => m.role === "user");
    const assistantMsgs = messages.filter(m => m.role === "assistant");

    const summary = `【对话摘要】
用户共发起 ${userMsgs.length} 个请求。
主要话题：${userMsgs[0]?.content.slice(0, 30) ?? "无"}...
AI 提供了 ${assistantMsgs.length} 个回复。
最后状态：${assistantMsgs[assistantMsgs.length - 1]?.content.slice(0, 30) ?? "无"}...`;

    return summary;
  }

  // 智能压缩入口
  compress(messages) {
    let totalTokens = messages.reduce((sum, m) => sum + this.估算Token(m.content), 0);

    if (totalTokens <= this.maxTokens) {
      return messages; // 不需要压缩
    }

    console.log(`⚠ 历史过长（${totalTokens} tokens），开始压缩...`);

    // 生成摘要替换旧历史
    const 系统 = messages.filter(m => m.role === "system");
    const 对话 = messages.filter(m => m.role !== "system");

    const summaryMsg = {
      role: "system",
      content: "【早期对话摘要】\n" + this.summarize(对话),
    };

    const 压缩后 = [summaryMsg, ...对话.slice(-5)]; // 摘要 + 最近5条
    console.log(`✅ 压缩完成：${messages.length} 条 → ${压缩后.length} 条`);
    return [...系统, ...压缩后];
  }
}

// 测试
const compactor = new ContextCompactor(2000);
const 长历史 = Array.from({ length: 20 }, (_, i) => ({
  role: i % 2 === 0 ? "user" : "assistant",
  content: `这是第 ${i + 1} 条消息，内容是一些较长的对话记录。`,
}));

const 压缩后 = compactor.compress(长历史);
console.log("压缩后:", 压缩后.length, "条消息");
```
