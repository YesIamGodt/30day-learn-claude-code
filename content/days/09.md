# Day 9: Token 计费：AI 是怎么算钱的？

## 这一节要解决什么问题？

AI 按"Token"收费。输入和输出都算钱。了解 Token 用量，才能控制成本。

## Token 是什么？

Token = AI 处理文本的基本单位。大约：
- 1 个 Token ≈ 0.75 个英文单词
- 1 个 Token ≈ 1-2 个中文字符

所以"你好，世界"大约 5-6 个 Token。

## Claude API 定价（参考）

| 模型 | 输入（$/百万） | 输出（$/百万） |
|------|-------------|-------------|
| Claude Sonnet | $3 | $15 |
| Claude Haiku | $0.8 | $4 |

## 代码演示

```js
// 简单 Token 计数（粗略估计）
function 估算Token数(text) {
  // 英文：按空格分割，粗略估算
  const 英文词数 = text.split(/\s+/).length;
  // 中文：按字符数估算
  const 中文字符数 = (text.match(/[\u4e00-\u9fa5]/g) || []).length;
  const 英文Token = Math.ceil(英文词数 * 1.3); // 每词约 1.3 token
  const 中文Token = 中文字符数; // 每中文字约 1 token
  return Math.ceil(英文Token + 中文Token);
}

// Anthropic 定价
const PRICING = {
  "claude-sonnet-4-7-20250514": { input: 3, output: 15 }, // $/百万token
};

function 计算成本(inputText, outputText, model) {
  const inputTokens = 估算Token数(inputText);
  const outputTokens = 估算Token数(outputText);
  const pricing = PRICING[model];

  const inputCost = (inputTokens / 1_000_000) * pricing.input;
  const outputCost = (outputTokens / 1_000_000) * pricing.output;

  return {
    inputTokens,
    outputTokens,
    totalTokens: inputTokens + outputTokens,
    inputCost: inputCost.toFixed(6),
    outputCost: outputCost.toFixed(6),
    totalCost: (inputCost + outputCost).toFixed(6),
  };
}

// 测试
const result = 计算成本(
  "请用 Python 写一个快速排序",
  "def quick_sort(arr): ...",
  "claude-sonnet-4-7-20250514"
);

console.log("Token 使用报告:");
console.log(`  输入: ${result.inputTokens} tokens ($${result.inputCost})`);
console.log(`  输出: ${result.outputTokens} tokens ($${result.outputCost})`);
console.log(`  总计: ${result.totalTokens} tokens ($${result.totalCost})`);
```

## 知识点

- Token 是 AI 计费的基本单位
- 简单估算：中文按字符数，英文按词数 × 1.3
- 精确计数需要用 `tiktoken` 库（Python）或专用 JS 库
- 成本 = (Token数 / 1,000,000) × 每百万价格
