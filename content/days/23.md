      `AgentTeam` 是多 Agent 的核心抽象：

# Day 23: 多 Agent 协作

## 这一节要解决什么问题？

一个 Agent 能力有限。多 Agent 协作：让多个专门化的 Agent 一起工作——一个负责规划，一个负责执行，一个负责审查。

## 角色分工设计

```
用户请求
    ↓
Coordinator Agent（协调者）
    ↓ 分解任务
┌───┴───┐
↓       ↓
Coder    Reviewer
Agent    Agent
↓       ↓
执行     审查
└───┬───┘
    ↓
整合结果 → 用户
```

## 知识进阶：多 Agent 的三种协作模式

| 模式 | 描述 | 适用场景 |
|------|------|---------|
| **并行广播** | 所有 Agent 收到相同任务，同时执行 | 投票、集体审查 |
| **串行管道** | Agent A 输出 → Agent B 输入 → ... | 流水线处理 |
| **协调者模式** | 中央协调者分配任务给专业 Agent | 复杂任务分解 |

## Python 真实源码解析

```python
# agent.py — 多 Agent 协作核心实现

import asyncio
from typing import Optional
from anthropic import Anthropic  # Anthropic 官方 SDK

class Agent:
    """
    单个 Agent：持有一个身份，具备独立思考和执行能力。
    Agent 是完全独立的实体，有自己的系统提示（role）。
    """

    def __init__(self, name: str, role: str, api_key: Optional[str] = None):
        self.name = name           # Agent 名称，如 "coder"
        self.role = role           # Agent 角色描述，如 "资深 Python 程序员"
        # 持有自己的 API 客户端（也可以共享同一个客户端）
        self.client = Anthropic(api_key=api_key or "")

    async def run(self, task: str) -> str:
        """
        执行任务：发送任务描述给 Claude，返回结果文本。
        注意是 async，可以与其他 Agent 并行运行。
        """
        response = self.client.messages.create(
            model="claude-opus-4-5",
            max_tokens=1024,
            messages=[
                # 系统消息注入 Agent 身份
                {"role": "system", "content": f"你是 {self.name}，角色: {self.role}"},
                {"role": "user", "content": task},
            ],
        )
        return response.content[0].text


class AgentTeam:
    """
    Agent 团队：管理多个 Agent，支持并行执行。
    所有注册到团队的 Agent 可以同时处理任务。
    """

    def __init__(self):
        self.agents: dict[str, Agent] = {}

    def add(self, agent: Agent):
        """向团队注册一个 Agent"""
        self.agents[agent.name] = agent

    async def run_parallel(self, task: str) -> dict[str, str]:
        """
        并行执行：所有 Agent 同时处理同一个任务。
        asyncio.gather() 是关键——它等待所有协程完成，
        返回结果列表，再用 zip() 组装成字典。
        """
        coroutines = [agent.run(task) for agent in self.agents.values()]
        results = await asyncio.gather(*coroutines)
        return dict(zip(self.agents.keys(), results))
```

### 进阶：实现协调者模式的 AgentTeam

```python
# 协调者模式：在并行执行前增加任务分解
class CoordinatedAgentTeam(AgentTeam):
    async def run_coordinated(self, task: str, coordinator: Agent) -> dict[str, str]:
        """
        1. 协调者分析任务，生成执行计划
        2. 将子任务分配给对应 Agent
        3. 各 Agent 并行执行子任务
        4. 协调者汇总结果
        """
        # 步骤 1：协调者分析任务
        plan = await coordinator.run(
            f"分析以下任务并分解为子任务，给每个子任务指定负责 Agent：\n{task}"
        )
        print(f"协调者计划: {plan}")

        # 步骤 2 & 3：并行执行（简化版：所有 Agent 都执行完整任务）
        return await self.run_parallel(task)
```

## 代码演示

```js
// 单个 Agent
class SimpleAgent {
  constructor(name, role, systemPrompt) {
    this.name = name;
    this.role = role;
    this.systemPrompt = systemPrompt;
    this.messages = [{ role: "system", content: systemPrompt }];
  }

  async chat(message) {
    this.messages.push({ role: "user", content: message });
    // 模拟 AI 调用
    return `【${this.name}】已收到: ${message.slice(0, 50)}...`;
  }

  receive(message, from) {
    this.messages.push({ role: "user", content: `[来自${from}]: ${message}` });
  }
}

// 多 Agent 系统
class MultiAgentSystem {
  constructor() {
    this.agents = new Map();
  }

  register(agent) {
    this.agents.set(agent.name, agent);
    console.log(`✅ 注册 Agent: ${agent.name} (${agent.role})`);
  }

  // 协调者分配任务
  async coordinate(task) {
    const coordinator = this.agents.get("coordinator");
    if (!coordinator) throw new Error("缺少协调者 Agent");

    const plan = await coordinator.chat(task);
    console.log("📋 协调者计划:", plan);

    // 分发给专业 Agent
    const coder = this.agents.get("coder");
    const reviewer = this.agents.get("reviewer");

    if (coder) {
      const code = await coder.chat("根据计划写代码: " + plan);
      console.log("💻 Coder:", code.slice(0, 80));
    }

    if (reviewer) {
      const review = await reviewer.chat("审查代码");
      console.log("🔍 Reviewer:", review.slice(0, 80));
    }

    return "多 Agent 协作完成";
  }
}

// 启动
const system = new MultiAgentSystem();
system.register(new SimpleAgent("coordinator", "协调者", "你是协调者，负责分解任务。"));
system.register(new SimpleAgent("coder", "程序员", "你是资深程序员，负责写代码。"));
system.register(new SimpleAgent("reviewer", "审查员", "你是代码审查员，负责审查代码质量。"));

system.coordinate("写一个排序算法").then(r => console.log("结果:", r));
```

## 面试与延伸问题

1. **`asyncio.gather()` 和串行执行相比快多少？** 如果每个 Agent 耗时 T 秒，N 个 Agent 并行执行总耗时约 T 秒（忽略通信开销），而串行执行需要 N×T 秒。
2. **多个 Agent 同时修改同一文件怎么办？** 需要引入文件锁（File Locking）或乐观并发控制（Optimistic Concurrency Control）；也可以让 Agent 之间传递"操作意图"，协调者负责合并冲突。
3. **如何让 Agent 之间共享上下文？** 可以通过共享消息历史（`AgentTeam` 中维护一个共享的 `messages` 列表）或使用黑板系统（Blackboard Pattern）：所有 Agent 读写一块共享存储。
4. **Agent 的角色描述（role）能动态更新吗？** 可以，例如在执行过程中协调者发现需要额外的专业知识，可以动态修改对应 Agent 的系统提示词来扩展其能力。
