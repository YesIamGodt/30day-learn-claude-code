      这是 Claude Code 记忆系统的核心实现。相比 JS Demo 侧重展示"启动时组装上下文"的业务流程，Python 源码更贴近实际生产环境：把记忆持久化到磁盘，确保会话结束后数据不丢失。

      ### 目录结构设计

      `MemoryStore` 默认将所有记忆文件存放在 `.claude/memory/` 目录下：

      - `system.json`：系统级记忆（每次启动都加载的提示）
      - `user_{userId}.json`：用户画像（偏好、语言、习惯等）
      - `{projectId}.json`：项目级记忆（项目背景、技术栈等）

      每个记忆文件都是独立的 JSON，这种设计有几个重要优点：

      1. **隔离性**：不同类型的记忆不会相互污染
      2. **按需加载**：不需要一次性加载所有记忆，按需读取

      `save()` 方法使用 `json.dump()` 写入，`load()` 使用 `json.load()` 读取。注意 `ensure_ascii=False` 参数——这确保中文字符不会被转义成 `\uXXXX` 形式，保持文件可读性。

      `list_keys()` 是一个实用方法，用 `pathlib.Path.glob("*.json")` 扫描目录，返回所有已存储的记忆键名，便于列出一段时间内积累的所有记忆。

      ### 与 JS Demo 的关系

# Day 22: 跨会话记忆

## 这一节要解决什么问题？

每次打开 Claude Code，它就忘了上次说了什么。跨会话记忆：让 AI 能记住用户偏好、项目背景、之前的工作。

## 记忆分层架构

```
┌─────────────────────────────────────────────┐
│              AI 启动上下文                    │
├─────────────────────────────────────────────┤
│  system.json    → 系统级提示（每次都加载）      │
│  user_xxx.json  → 用户偏好（语言、风格等）     │
│  project.json   → 项目背景（技术栈、目录结构）  │
└─────────────────────────────────────────────┘
          ↓ 启动时按需组装
     完整上下文 → 发给 AI
```

## 知识进阶：记忆存储的几种方案

除了文件系统，还有其他存储方案，各有优劣：

| 方案 | 优点 | 缺点 |
|------|------|------|
| JSON 文件（本章） | 简单、无依赖、可读 | 并发写入有风险 |
| SQLite | 支持复杂查询、并发安全 | 需要数据库依赖 |
| 向量数据库（FAISS） | 支持语义检索 | 部署复杂 |
| 云存储（Redis/S3） | 跨设备同步 | 需要网络和账户 |

Claude Code 早期版本选择 JSON 文件，是因为它**零依赖、够用、调试方便**。随着功能复杂化，未来可能迁移到更强大的存储。

### Python 真实源码解析

```python
# memory.py — 记忆存储核心实现

import json
from pathlib import Path

class MemoryStore:
    """
    基于文件系统的记忆存储系统。
    所有记忆以 JSON 格式保存在 .claude/memory/ 目录下。
    """

    def __init__(self, memdir: str = ".claude/memory"):
        # Path 对象比字符串更安全，自动处理路径分隔符
        self.memdir = Path(memdir)
        # 确保目录存在（parents=True 允许递归创建）
        self.memdir.mkdir(parents=True, exist_ok=True)

    # 保存记忆到磁盘
    def save(self, key: str, value: dict) -> None:
        """
        Args:
            key: 记忆的唯一标识，如 "user_alice" 或 "project_backend"
            value: 要保存的字典数据
        """
        path = self.memdir / f"{key}.json"
        # ensure_ascii=False 保证中文原文存储，不转义为 \uXXXX
        with open(path, "w", encoding="utf-8") as f:
            json.dump(value, f, ensure_ascii=False, indent=2)

    # 从磁盘加载记忆
    def load(self, key: str) -> dict | None:
        """
        Returns:
            加载的记忆字典，不存在则返回 None
        """
        path = self.memdir / f"{key}.json"
        if not path.exists():
            return None
        with open(path, encoding="utf-8") as f:
            return json.load(f)

    # 列出所有已存储的记忆键
    def list_keys(self) -> list[str]:
        """
        扫描目录返回所有 .json 文件的主文件名。
        用于查看当前积累了多少记忆，或枚举所有项目记忆。
        """
        return [p.stem for p in self.memdir.glob("*.json")]
```

## 代码演示

```js
const fs = require("fs");
const path = require("path");

class MemorySystem {
  constructor(memoryDir = ".claude/memory") {
    this.memoryDir = memoryDir;
    this.systemPrompt = "";
    this.userProfile = {};
    this.projectContext = "";
  }

  ensureDir() {
    if (!fs.existsSync(this.memoryDir)) {
      fs.mkdirSync(this.memoryDir, { recursive: true });
    }
  }

  // 系统级记忆（每次对话都加载）
  loadSystemMemory() {
    const file = path.join(this.memoryDir, "system.md");
    if (fs.existsSync(file)) {
      this.systemPrompt = fs.readFileSync(file, "utf-8");
    }
    return this.systemPrompt;
  }

  saveSystemMemory(content) {
    this.ensureDir();
    const file = path.join(this.memoryDir, "system.md");
    fs.writeFileSync(file, content, "utf-8");
    this.systemPrompt = content;
  }

  // 用户画像（偏好设置）
  loadUserProfile(userId) {
    const file = path.join(this.memoryDir, `user_${userId}.json`);
    if (fs.existsSync(file)) {
      this.userProfile = JSON.parse(fs.readFileSync(file, "utf-8"));
    }
    return this.userProfile;
  }

  saveUserProfile(userId, profile) {
    this.ensureDir();
    const file = path.join(this.memoryDir, `user_${userId}.json`);
    fs.writeFileSync(file, JSON.stringify(profile, null, 2), "utf-8");
    this.userProfile = profile;
  }

  // 项目上下文
  loadProjectContext(projectPath) {
    const file = path.join(projectPath, ".claude/memory.md");
    if (fs.existsSync(file)) {
      this.projectContext = fs.readFileSync(file, "utf-8");
    }
    return this.projectContext;
  }

  // 启动时组装完整上下文
  buildStartupContext(userId, projectPath) {
    const parts = [];
    const system = this.loadSystemMemory();
    const profile = this.loadUserProfile(userId);
    const project = this.loadProjectContext(projectPath);

    if (system) parts.push(system);
    if (profile.name) parts.push(`用户名为 ${profile.name}`);
    if (profile.preferences?.language) parts.push(`偏好语言：${profile.preferences.language}`);
    if (project) parts.push(`项目背景：\n${project}`);

    return parts.join("\n\n");
  }
}

// 测试
const memory = new MemorySystem();
memory.saveSystemMemory("你是一个乐于助人的 AI 编程助手。");
memory.saveUserProfile("default", { name: "小明", preferences: { language: "JavaScript" } });

const startup = memory.buildStartupContext("default", process.cwd());
console.log("启动上下文:");
console.log(startup);
```

## 面试与延伸问题

1. **记忆存储在数据库和文件系统各有什么坑？** 文件系统简单但有并发冲突风险（两个进程同时写同一文件）；数据库需要事务保护，但查询能力更强。
2. **如何防止记忆文件无限膨胀？** 实现 TTL（Time-To-Live）机制，超过一定时间的记忆自动归档或删除；也可以按记忆重要度分级，核心记忆永久保留，次要记忆定期清理。
3. **用户隐私如何保护？** 记忆文件应放在用户目录（`~/.claude/`）而非项目目录；敏感内容（如 API Key）不应存入记忆。
4. **如何实现记忆的增量更新？** 不是每次更新都全量覆盖，而是用 JSON Merge Patch（RFC 7396）只更新变化的字段，保留历史版本。
