# Day 12: 上下文窗口：AI 能记多少？

## 这一节要解决什么问题？

AI 的"记忆容量"是有限的，叫做**上下文窗口**。Claude 3.5 Sonnet 的上下文窗口是 200K tokens。如果超过，AI 就会"失忆"。

## 上下文窗口就像工作台

想象你的桌子（上下文窗口）：
- 桌上只能放 200 张纸
- 放更多就要把旧的收起来
- 怎么放、放哪些，决定了 AI 能否有效工作

## 代码演示

```js
class ContextManager {
  constructor(maxTokens = 10000) {
    this.maxTokens = maxTokens;
  }

  估算Token数(text) {
    const 英文词数 = text.split(/\s+/).length;
    const 中文字符数 = (text.match(/[\u4e00-\u9fa5]/g) || []).length;
    return Math.ceil(英文词数 * 1.3 + 中文字符数);
  }

  估算消息总Token(messages) {
    return messages.reduce((sum, msg) => {
      return sum + this.估算Token数(msg.content) + 10; // +10 是元数据开销
    }, 0);
  }

  截断到限制(messages) {
    let 总Token数 = this.估算消息总Token(messages);
    if (总Token数 <= this.maxTokens) {
      return messages; // 不需要截断
    }

    // 从旧到新逐条删除，直到满足限制
    const result = [...messages];
    while (this.估算消息总Token(result) > this.maxTokens && result.length > 2) {
      result.shift(); // 删除最早的消息
    }

    console.log(`⚠ 上下文超限，截断到 ${result.length} 条消息`);
    return result;
  }

  统计(messages) {
    const tokens = this.估算消息总Token(messages);
    const percent = Math.round((tokens / this.maxTokens) * 100);
    return {
      tokens,
      max: this.maxTokens,
      percent,
      警告: percent > 80 ? "⚠ 接近上限！" : percent > 50 ? "✓ 安全" : "✓ 充裕",
    };
  }
}

// 测试
const manager = new ContextManager(1000); // 假设只有 1000 token
const 大量消息 = [
  { role: "user", content: "早上好！今天天气不错。" },
  { role: "assistant", content: "是的，今天天气很好！" },
  { role: "user", content: "我们继续昨天的项目吧。" },
];

const stat = manager.统计(大量消息);
console.log("上下文统计:", stat);
console.log("截断后:", manager.截断到限制(大量消息).length, "条消息");
```
