      ## CommandRegistry — 斜杠命令注册中心

      斜杠命令系统本质上是一个"命令注册表"模式。核心思路是：**把命令名映射到处理器函数**。这个设计在 CLI 工具中非常常见，从 Git 到 npm 都用它。

      为什么要用注册制而不是 if/else 链？因为注册制的可扩展性极强：
      - 新增命令只需要 `register()`，不需要修改判断逻辑
      - 每个命令可以独立开发和测试
      - 命令列表可以动态生成（`list_all()`）

      `Command` 数据类封装了每个命令的元信息：`name`（唯一标识）、`description`（帮助文本）、`handler`（实际执行的异步函数）。这种封装让命令的"是什么"和"做什么"分离，后续可以轻松扩展（比如加 `aliases` 别名、`args_schema` 参数定义）。

      `is_command()` 的实现很巧妙：它只检查文本是否以 `/` 开头，然后提取命令名。这比正则匹配简单得多，效率也够用。但它的局限是：它无法区分 `/help` 和 `/helpme`（都识别为 `help`），如果需要更精细的命令解析，需要引入参数模式匹配。

# Day 16: 斜杠命令：/help /exit

## 这一节要解决什么问题？

在 REPL 里，当你输入普通消息时，Claude Code 会把它发送给 AI 处理。但有些操作不需要 AI——它们是纯本地的、与 AI 能力无关的系统操作。

比如：
- `/help`：查看所有可用命令列表
- `/exit`：退出程序
- `/clear`：清空对话历史
- `/model claude-opus-4-5`：切换 AI 模型

如果这些也发给 AI，AI 要先"理解"你要退出程序，然后回复"好的，再见"，再让程序退出。这太慢了，而且 AI 不一定能准确理解你的意图（它可能以为你在打招呼而不是要退出）。

斜杠命令系统就是为这些场景设计的：**以 `/` 开头的输入，直接在本地路由处理，不走 AI**。

## 命令解析流程

```
用户输入: "/model claude-opus-4-5"
              │
              ▼
        parse("/model claude-opus-4-5")
              │
     ┌────────┴────────┐
     │ input.startswith("/") │──→ No ──→ 传给 AI
     │ command = input[1:]   │──→ Yes ──┐
     └─────────────────────────┘        │
                                          ▼
                              cmd_name, args = split()
                                        │
                              cmd_registry.get(cmd_name)
                                        │
                         ┌───────────────┴───────────────┐
                         │ cmd found │                  │ cmd not found
                         ▼                           ▼
                    cmd.handler(args)              Error: 未知命令
                         │
                         ▼
                    返回结果（显示给用户）
```

## 基础知识

### 命令注册表模式

核心数据结构是一个从命令名到 `Command` 对象的字典：

```js
class CommandSystem {
  constructor() {
    this.commands = new Map();  // name → { handler, description }
  }

  // 注册命令：把命令名和处理器函数关联起来
  register(name, handler, description = "") {
    this.commands.set(name, { handler, description });
  }

  // 解析输入：判断是命令还是普通消息
  parse(input) {
    if (!input.startsWith("/")) {
      return { isCommand: false, name: null, args: "" };
    }
    // 去掉 "/" 前缀，按空格分割，第一段是命令名，其余是参数
    const [name, ...args] = input.slice(1).split(/\s+/);
    return { isCommand: true, name, args: args.join(" ") };
  }

  // 执行命令：路由到对应处理器
  async execute(input) {
    const parsed = this.parse(input);
    if (!parsed.isCommand) return null;  // 非命令，不处理

    const cmd = this.commands.get(parsed.name);
    if (!cmd) {
      throw new Error(`未知命令: /${parsed.name}。输入 /help 查看所有命令。`);
    }
    return await cmd.handler(parsed.args);
  }

  // 自动生成帮助文本
  helpText() {
    const lines = ["可用命令:"];
    for (const [name, cmd] of this.commands) {
      lines.push(`  /${name}  - ${cmd.description}`);
    }
    return lines.join("\n");
  }
}
```

### 注册默认命令

```js
const commands = new CommandSystem();

// /help：列出所有命令
commands.register("help", () => commands.helpText(), "显示帮助");

// /exit：退出程序
commands.register("exit", () => { process.exit(0); }, "退出程序");

// /clear：清空历史
commands.register("clear", () => { /* 清空 this.history */ return "历史已清空"; }, "清空对话历史");

// /model：切换模型
commands.register("model", (args) => `模型切换为: ${args}`, "切换模型");

// /cost：Token 使用统计
commands.register("cost", () => `Token 使用: ${tokenCounter.total()}`, "显示 Token 统计");
```

## 进阶知识

### 命令别名支持

很多 CLI 工具支持命令别名，比如 `/h` 等于 `/help`：

```js
// 在 register 中加入别名支持
register(name, handler, description = "", aliases = []) {
  this.commands.set(name, { handler, description });
  for (const alias of aliases) {
    this.commands.set(alias, { handler, description });  // 别名指向同一个 handler
  }
}

// 使用
commands.register("help", showHelp, "显示帮助", ["h", "?"]);
```

### 带验证的参数解析

更复杂的命令需要参数验证：

```python
@dataclass
class Command:
    name: str
    description: str
    handler: Callable[..., Awaitable[str]]
    args_schema: dict | None = None  # 后续扩展：参数类型定义

# 未来可以这样用：
commands.register(
    "model",
    switch_model,
    "切换模型",
    args_schema={"type": "string", "required": True, "choices": ["opus", "sonnet"]}
)
```

## 代码演示

```js
// 命令系统：斜杠命令的注册、解析、执行
class CommandSystem {
  constructor() {
    this.commands = new Map();
  }

  // 注册一个新命令
  register(name, handler, description = "") {
    this.commands.set(name, { handler, description });
  }

  // 解析输入：区分命令和普通消息
  parse(input) {
    if (!input.startsWith("/")) {
      return { isCommand: false, name: null, args: "" };
    }
    const [name, ...args] = input.slice(1).split(/\s+/);
    return { isCommand: true, name, args: args.join(" ") };
  }

  // 执行命令，路由到对应处理器
  async execute(input) {
    const parsed = this.parse(input);
    if (!parsed.isCommand) return null;  // 普通消息，返回 null 让调用方走 AI

    const cmd = this.commands.get(parsed.name);
    if (!cmd) {
      throw new Error(`未知命令: /${parsed.name}。输入 /help 查看所有命令。`);
    }
    return await cmd.handler(parsed.args);  // 执行命令处理器
  }

  // 生成帮助文本
  helpText() {
    const lines = ["可用命令:"];
    for (const [name, cmd] of this.commands) {
      lines.push(`  /${name}  - ${cmd.description}`);
    }
    return lines.join("\n");
  }
}

// 创建命令系统并注册内置命令
const commands = new CommandSystem();
const ctx = { history: [], model: "claude-sonnet-4-7-20250514", tokenCounter: null };

commands.register("help", () => commands.helpText(), "显示帮助");
commands.register("exit", () => { process.exit(0); }, "退出程序");
commands.register("clear", () => { ctx.history = []; return "历史已清空"; }, "清空对话历史");
commands.register("model", (args) => { ctx.model = args; return `模型切换为: ${args}`; }, "切换模型");
commands.register("cost", () => {
  const total = ctx.tokenCounter?.total() ?? 0;
  return `当前会话 Token 使用: ${total}`;
}, "显示 Token 统计");

// 测试
(async () => {
  console.log(await commands.execute("/help"));
  console.log(await commands.execute("/model claude-opus-4-5"));
  console.log(await commands.execute("/unknown"));  // 触发错误
})().catch(e => console.error(e.message));
```

## 知识点速查表

| 概念 | 说明 |
|------|------|
| 命令注册表 | `Map<name, Command>` 存储命令名到处理器的映射 |
| 斜杠前缀 | `/` 是命令的标识符，用于区分普通消息和系统命令 |
| 命令解析 | `input.slice(1).split(/\s+/)` 提取命令名和参数 |
| 路由 | 根据解析出的命令名查找处理器并执行 |
| 帮助文本 | 动态遍历注册表生成，不需要硬编码命令列表 |
| 别名 | 多个命令名指向同一个 handler，实现简单 |

## 面试题

1. **如何在不修改命令系统代码的情况下，让用户自定义斜杠命令？**思路是"命令热注册"：用户可以在配置文件中定义命令，程序启动时从配置文件加载。配置文件格式可以是 JSON 或 YAML，每条命令定义 `name`、`handler`（用字符串表示的代码片段或内嵌 DSL）和 `description`。程序启动时遍历配置，调用 `register()` 批量注册。这种设计把"有什么命令"从代码移到配置，符合开放-封闭原则。

2. **命令系统的错误处理策略是什么？命令执行失败时应该返回什么？**命令处理器应该返回 `Result<T, Error>` 风格的返回值（成功时返回结果，失败时返回错误信息），而不是直接抛异常。抛异常会让调用方（REPL）不知所措，返回错误字符串可以让 REPL 直接展示给用户。更严谨的设计是用 discriminated union（TypeScript 可以用 `{ ok: true, value: T } | { ok: false, error: string }`）来区分成功和失败。
