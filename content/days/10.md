# Day 10: 对话主循环 REPL

## 这一节要解决什么问题？

REPL = **R**ead-**E**val-**P**rint **L**oop。就是一个"死循环"：等用户输入 → 处理 → 输出 → 继续等。

Node.js 本身就是 REPL。你的 Claude Code 也需要一个。

## 代码演示

```js
// 模拟 REPL（不需要真实 API Key）
class SimpleREPL {
  constructor() {
    this.history = [];
    this.running = false;
  }

  printWelcome() {
    console.log("=".repeat(50));
    console.log("  Claude Code — REPL 对话");
    console.log("=".repeat(50));
    console.log("输入消息和 Claude 对话");
    console.log("命令: /help, /exit, /clear, /history");
    console.log();
  }

  handleCommand(input) {
    switch (input.toLowerCase()) {
      case "/exit":
      case "/quit":
      case "/q":
        console.log("再见！");
        this.running = false;
        return false;

      case "/help":
        console.log("可用命令:");
        console.log("  /help    - 显示帮助");
        console.log("  /exit    - 退出");
        console.log("  /clear   - 清空历史");
        console.log("  /history - 显示历史");
        return true;

      case "/clear":
        this.history = [];
        console.log("历史已清空");
        return true;

      case "/history":
        if (this.history.length === 0) {
          console.log("（无历史）");
        } else {
          this.history.forEach((msg, i) => {
            console.log(`${i + 1}. [${msg.role}] ${msg.content.slice(0, 50)}...`);
          });
        }
        return true;

      default:
        return false;
    }
  }

  simulateResponse(userInput) {
    // 模拟 AI 回复
    const responses = [
      "收到！我理解了。让我帮你处理。",
      "这是个有趣的问题。我来分析一下……",
      "好的，我来执行这个任务。",
    ];
    return responses[Math.floor(Math.random() * responses.length)];
  }

  // 运行 REPL（Node.js readline）
  async run() {
    const readline = require("readline");
    this.running = true;
    this.printWelcome();

    const rl = readline.createInterface({
      input: process.stdin,
      output: process.stdout,
    });

    const ask = () => {
      if (!this.running) {
        rl.close();
        return;
      }
      rl.question("你: ", async (userInput) => {
        const input = userInput.trim();
        if (!input) { ask(); return; }

        // 先检查是否特殊命令
        const isCommand = this.handleCommand(input);
        if (!isCommand) {
          // 加到历史
          this.history.push({ role: "user", content: input });
          // 模拟 AI 回复
          const response = this.simulateResponse(input);
          console.log(`Claude: ${response}`);
          this.history.push({ role: "assistant", content: response });
        }

        ask();
      });
    };

    ask();
  }
}

// 运行
console.log("（Node.js readline REPL 需要真实终端环境）");
console.log("以下是模拟演示:");
const repl = new SimpleREPL();
repl.history.push({ role: "user", content: "你好" });
console.log("你: 你好");
console.log("Claude:", repl.simulateResponse("你好"));
console.log("\n输入 /help 查看所有命令");
```

## 知识点

- REPL 四步曲：Read → Eval → Print → Loop
- `readline.createInterface()` — Node.js 读取用户输入
- `rl.question()` — 异步等待用户输入
- 特殊命令（`/exit`、`/help`）先拦截，不发给 AI

把 `simulateResponse` 改成根据用户输入返回更有意义的回复。
