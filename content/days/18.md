# Day 18: Plan 模式：AI 行动前先做计划

## 这一节要解决什么问题？

AI 直接执行可能会做错事（删错文件、调用错误 API）。Plan 模式：在 AI 执行前，先让它说出计划，用户确认后再行动。

## 代码演示

```js
class PlanMode {
  constructor(client) {
    this.client = client;
    this.enabled = false;
  }

  enable() { this.enabled = true; }
  disable() { this.enabled = false; }

  // 生成计划
  async 生成计划(task) {
    const prompt = `任务：${task}

请分步骤说明你会怎么做。用以下格式：

## 计划
1. 第一步：...
2. 第二步：...
3. 第三步：...

## 预估影响
（简要说明每步的影响）

确认以上计划无误后，我会按顺序执行。`;

    const response = await this.client.messages.create({
      model: "claude-sonnet-4-7-20250514",
      max_tokens: 800,
      messages: [{ role: "user", content: prompt }],
    });

    return response.content[0].text;
  }

  // 带确认的执行
  async 执行带确认(task, executor) {
    if (!this.enabled) {
      return await executor(task);
    }

    const plan = await this.生成计划(task);
    console.log("\n📋 AI 计划：");
    console.log(plan);
    console.log("\n按 Enter 确认执行，或输入 '取消' 终止：");

    // 简化：直接执行（真实环境用 readline 等待用户确认）
    const confirmed = true; // await waitForConfirmation();
    if (!confirmed) {
      return { success: false, message: "用户取消" };
    }

    return await executor(task);
  }
}

// 测试
const planMode = new PlanMode();
planMode.enable();
console.log("Plan 模式：", planMode.enabled ? "开启" : "关闭");
console.log("\nPlan 模式可以让 AI 先说计划，用户确认后再执行。");
console.log("这避免了 AI 直接执行危险操作。");
```
