      ## BashTool — 执行 Shell 命令

      BashTool 是 Claude Code 中最常用的工具之一，负责在宿主机上执行真实的 shell 命令。代码很短，但每个细节都值得注意：

      ```python
      async def execute(self, command: str, timeout: int = 30) -> str:
          try:
              proc = await asyncio.wait_for(
                  asyncio.create_subprocess_shell(command, ...),
                  timeout=timeout,
              )
              stdout, stderr = await proc.communicate()
              return stdout.decode() + stderr.decode()
          except asyncio.TimeoutError:
              proc.terminate()
              return f"错误: 命令执行超时（{timeout}秒）"
      ```

      关键点：
      - `asyncio.create_subprocess_shell` 是 Python 异步执行命令的方式，与 Node.js 的 `child_process.spawn` 对应
      - `asyncio.wait_for(..., timeout)` 在超时时主动取消进程，防止僵尸进程
      - `proc.terminate()` 发送 SIGTERM 信号，让进程优雅退出（而非 `kill()` 的强制杀死）
      - stdout 和 stderr 合并返回，因为分开处理对 AI 来说往往过于冗长

      注意：`create_subprocess_shell` 直接执行字符串命令，与 Python 官方推荐的 `create_subprocess_exec`（传列表）相比存在注入风险。但在 Claude Code 场景下，命令完全由 AI 模型生成（而非用户直接输入），风险相对可控，但这是值得面试时讨论的安全权衡点。

# Day 2: 边等边做事：异步是什么？

## 这一节要解决什么问题？

想象你要烧水，但用的是同步方式：把水壶放上灶 → **等待**烧开 → 泡茶。听起来很正常对吧？但如果你是餐厅厨师，同步方式就完蛋了——水在烧的时候你只能干等着，什么菜都做不了。异步的方式是：把水壶放上灶 → **去炒菜** → 水开了回来泡茶。**等待的时候不闲着**，这就是异步的核心思想。

在软件世界里，"烧水"无处不在：发网络请求（等几百毫秒）、读文件（等磁盘 IO）、执行系统命令（等进程完成）。这些操作的特点是：**程序发起请求后，需要等待外部系统完成工作，在这段时间里 CPU 其实是空闲的**。同步编程让 CPU 空等着，异步编程让 CPU 在等待期间去处理其他任务。

对 AI Agent 来说，异步尤其重要。调用一次 Claude API 要花 200-500ms，期间程序完全可以准备下一轮的工具调用、检查参数合法性、记录日志。如果用同步方式，整个 Agent 就真的"卡住"了——CPU 空闲，内存闲置，其他操作全部阻塞。

Python 的 `asyncio` 和 Node.js 的 `async/await` 是目前最流行的两种异步编程方案。两者的核心思想完全一致：都用**协程**（Coroutine）替代线程，用**事件循环**（Event Loop）替代多进程调度，只是语法和生态略有不同。

## 概念图解

```
+----------------------------------------------------------+
|              同步 vs 异步：时间线对比                      |
+----------------------------------------------------------+

同步方式（单线程）:
  时间 →

  [等待API响应......][处理结果][等待文件读取......][处理结果]
  |_____________________| |_____________________|
     这 500ms CPU 完全空闲    这 200ms CPU 也完全空闲


异步方式（事件循环）:
  时间 →

  [发起API请求  ][处理结果]
       ↓ (等待时)
  [处理其他事    ][读取文件  ][处理结果]
                              ↓ (等待时)
                         [处理其他事...  ][返回最终结果]

  同一时间段内，CPU 在多个任务之间切换，全部填满！


+----------------------------------------------------------+
|              Python asyncio 事件循环原理                   |
+----------------------------------------------------------+

  事件循环（Event Loop）:
    while True:
        任务队列 = [读文件任务, API请求任务, 定时器回调, ...]

        for 任务 in 任务队列:
            if 任务.已就绪():
                任务.执行()           # 不阻塞，立即返回
            else:
                等待.挂起()           # 协程让出 CPU

        if 全部任务完成: break
```

## 基础知识

### 1. async/await 基础

`async` 关键字声明一个**异步函数**，调用它会返回一个 `Promise`（JS）或 `Coroutine`（Python）。`await` 只能在 `async` 函数内部使用，它的作用是"等待"一个 Promise 完成，但**不会阻塞事件循环**——等待期间，程序可以去执行其他代码。

```js
// async 函数：声明方式是同步的，只有执行时才可能"异步"
async function 发消息给AI(问题) {
  // await：等 fetch 完成，但不会卡住调用者
  const response = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ messages: [{ role: "user", content: 问题 }] }),
  });
  // 上一行 await 完成之后，才会执行到这里
  const data = await response.json();
  return data;
}

// 调用：async 函数返回 Promise，必须用 await 或 .then() 处理
(async () => {
  const result = await 发消息给AI("你好");
  console.log("收到回复:", result);
})();
```

### 2. 并行执行：Promise.all

很多情况下，多个异步操作互不依赖，应该**并行**执行而非串行。用 `Promise.all` 同时发起多个请求，总耗时等于最慢的那个，而非相加：

```js
// 串行：先问天气，再问时间，总耗时 = 300ms + 200ms = 500ms
async function 串行获取() {
  const 天气 = await 获取天气();      // 等 300ms
  const 时间 = await 获取时间();      // 等 200ms
  return { 天气, 时间 };
}

// 并行：同时发起，总耗时 = max(300ms, 200ms) = 300ms
async function 并行获取() {
  const [天气, 时间] = await Promise.all([
    获取天气(),  // 同时开始
    获取时间(),   // 同时开始
  ]);
  return { 天气, 时间 };
}
```

### 3. Python asyncio 写法

Python 的 `asyncio` 与 JS 的 `async/await` 几乎是一一对应的：

```python
import asyncio

# Python 的 async def 等价于 JS 的 async function
async def fetch_data():
    # await 等价于 JS 的 await
    await asyncio.sleep(2)  # 模拟异步 IO，等 2 秒
    return "数据准备好了"

async def main():
    result = await fetch_data()
    print(result)

# Python 3.7+ 推荐写法
asyncio.run(main())
```

## 进阶知识

### 错误处理：try/except 与 Promise.catch

异步代码的错误处理稍有不同——`try/except` 捕获异步函数内的异常，`await` 语句会把 Promise 的 reject 转为抛出异常：

```js
async function 安全调用AI() {
  try {
    const response = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      // ...
    });
    if (!response.ok) {
      // HTTP 错误（非 2xx）不会在 fetch 层面抛出，需要手动判断
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }
    return await response.json();
  } catch (error) {
    // 捕获网络错误（断网）或上面 throw 的错误
    console.error("AI 调用失败:", error.message);
    return null;
  }
}
```

### 异步迭代器：处理流式数据

AI 的流式输出（如 Claude 的 streaming）是典型的**异步迭代器**模式。数据一块一块地到达，不用等全部完成就能处理：

```js
// 异步迭代器：每次 yield 一块数据
async function* 流式读取(url) {
  const response = await fetch(url);
  const reader = response.body.getReader(); // 流读取器

  while (true) {
    const { done, value } = await reader.read(); // 异步读取下一块
    if (done) break;
    yield new TextDecoder().decode(value);        // yield 出去
  }
}

// 使用：for await...of 遍历异步迭代器
(async () => {
  for await (const chunk of 流式读取("https://api.anthropic.com/...")) {
    process.stdout.write(chunk); // 实时打印，不用等全部下载
  }
})();
```

## 代码演示

```js
// 同步版本：烧水时什么都不做
function 同步烧水() {
  console.log("把水壶放上灶...");
  const 水开了 = 等待毫秒(3000); // 程序卡住3秒！
  console.log("泡茶");
}

// 异步版本：等待时可以做别的
async function 异步烧水() {
  console.log("把水壶放上灶...");
  // 烧水的等待期间，去做别的事
  await new Promise(resolve => setTimeout(resolve, 3000));
  console.log("水开了，泡茶");
}

// 运行两个
console.log("=== 同步 ===");
同步烧水();
console.log("=== 异步 ===");
异步烧水();
console.log("我可以在等待期间做其他事！");
```

## 知识点速查表

| 概念 | JavaScript | Python | 说明 |
|------|-----------|--------|------|
| 异步函数声明 | `async function` | `async def` | 函数内可以使用 await |
| 等待异步完成 | `await promise` | `await coro` | 不阻塞事件循环 |
| 模拟等待 | `new Promise(r => setTimeout(r, 1000))` | `asyncio.sleep(1)` | 不占用 CPU 的定时等待 |
| 并行等待 | `Promise.all([p1, p2])` | `asyncio.gather(c1, c2)` | 同时执行，总耗时取最大 |
| 异步迭代器 | `for await (x of stream)` | `async for x in stream` | 处理流式数据 |
| 错误处理 | `try { await fn() } catch(e) {}` | `try: await fn() except: pass` | 捕获异步函数抛出的异常 |
| 启动异步 | `asyncFn().then(...)` 或 `await asyncFn()` | `asyncio.run(fn())` | Python 需要显式启动事件循环 |
