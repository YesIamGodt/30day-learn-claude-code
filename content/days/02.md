# Day 2: 边等边做事：异步是什么？

## 这一节要解决什么问题？

想象你要烧水，但用的是同步方式：
1. 把水壶放上灶 → **等待**烧开 → 泡茶

但异步方式是这样的：
1. 把水壶放上灶 → **去刷牙** → 水开了回来泡茶

**等待的时候不闲着**，这就是异步的核心思想。

## 为什么 AI 对话需要异步？

调用 AI API 要等几百毫秒。如果用同步方式，程序就"卡住"了。用异步，程序可以同时做别的事。

## 代码演示

```js
// 同步版本：烧水时什么都不做
function 同步烧水() {
  console.log("把水壶放上灶...");
  const 水开了 = 等待毫秒(3000); // 程序卡住3秒！
  console.log("泡茶");
}

// 异步版本：等待时可以做别的
async function 异步烧水() {
  console.log("把水壶放上灶...");
  // 烧水的等待期间，去做别的事
  await new Promise(resolve => setTimeout(resolve, 3000));
  console.log("水开了，泡茶");
}

// 运行两个
console.log("=== 同步 ===");
同步烧水();
console.log("=== 异步 ===");
异步烧水();
console.log("我可以在等待期间做其他事！");
```

## 知识点

- `async function` — 声明一个异步函数
- `await` — 等待一个 Promise 完成，但**不卡住程序**
- `new Promise(resolve => setTimeout(resolve, 3000))` — 模拟 3 秒等待
- `async` 函数返回的是 Promise，不需要 `.then()`

把上面代码里的 `3000` 改成 `5000`，运行看看输出顺序变化了没有。
