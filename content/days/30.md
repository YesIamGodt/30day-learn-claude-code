## 30 天掌握的核心概念

### 1. ReAct 循环 — AI 思考引擎

**观察 → 思考 → 行动 → 观察** 的循环，让 AI 能够推理并调用工具，是 Claude Code 的核心引擎。

### 2. 工具系统 — AI 的手脚

注册表模式（ToolRegistry）让新增工具变得简单，每个工具只需实现 `toSchema()` 和 `execute()` 两个接口。

### 3. MCP 协议 — 扩展 AI 能力

统一协议连接外部世界：数据库、GitHub、Slack……无需改动核心代码，第三方即可扩展。

### 4. 跨会话记忆 — 让 AI 更懂你

文件系统记忆存储，启动时组装上下文，让每次对话都基于之前的积累。

### 5. 多 Agent 协作 — 1+1 > 2

多个专业 Agent 并行工作，协调者分解任务，审查者把控质量，效率远超单个 Agent。
