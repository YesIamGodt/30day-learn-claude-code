# Day 1: 命令行入口

## 这一节要解决什么问题？

我们每天用电脑，点来点去是**图形界面**。但程序员更喜欢用**命令行**——只有文字，键盘输入，鼠标不需要。

Claude Code 本身就是一个命令行工具。所以第一步，我们给 Agent 做一个"命令行入口"。

## 什么是命令行参数？

运行命令时：

```bash
node index.js "帮我写一个排序算法" --verbose
```

- `node index.js` → 运行哪个程序
- `"帮我写一个排序算法"` → **位置参数**（必须提供，AI 知道要做什么）
- `--verbose` → **可选参数**（加了才生效，不加就忽略）

## 代码演示（可直接运行）

```js
// 解析命令行参数
const args = process.argv.slice(2); // 去掉 "node" 和 "index.js"

if (args.length === 0) {
  console.log("用法: node index.js <你的指令> [--verbose]");
  process.exit(1);
}

// 把 -- 开头的参数挑出来
const flags = args.filter(a => a.startsWith("--"));
const rest = args.filter(a => !a.startsWith("--"));

console.log("收到指令:", rest.join(" "));
console.log("flags:", flags);

if (flags.includes("--verbose")) {
  console.log("详细信息已开启");
  console.log("原始参数:", args);
}
```

运行：`node index.js "帮我写排序" --verbose`

## 知识点

- `process.argv` — Node.js 自带的命令行参数数组
- 位置参数：没有前缀，顺序决定含义
- 可选参数（flags）：以 `--` 开头
- `process.exit(1)` 表示程序异常退出，0 表示成功
