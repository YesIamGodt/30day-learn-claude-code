# Day 15: 里程碑：你的 AI 已经能跑了！

## 🎉 恭喜你走到这里！

前 14 天，我们一步一步构建了 Claude Code 的核心模块。现在，把它们拼在一起。

## 架构总览

```
                    用户输入（REPL）
                          ↓
              ┌───────── QueryEngine ─────────┐
              ↓                                 ↓
        特殊命令？                      发送给 AI
        (/help 等)                        ↓
              ↓                    ┌─────────┴────────┐
          本地处理                 ↓                   ↓
                            工具调用              最终回复
                                  ↓
                            ToolRegistry
                            ↓    ↓    ↓
                         Bash  文件  搜索
```

## 最小可用版本

```js
// 15 行代码的最小 Claude Code
const { ToolRegistry, BashTool, WebFetchTool } = require("./tools");

class ClaudeCode {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.registry = new ToolRegistry();
    this.registry.register(new BashTool());
    this.registry.register(new WebFetchTool());
    this.history = [];
  }

  async chat(message) {
    this.history.push({ role: "user", content: message });

    const response = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: {
        "x-api-key": this.apiKey,
        "anthropic-version": "2023-06-01",
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        model: "claude-sonnet-4-7-20250514",
        max_tokens: 4096,
        messages: this.history,
        tools: this.registry.list().map(t => t.toSchema()),
      }),
    });

    const data = await response.json();
    this.history.push({ role: "assistant", content: data.content[0].text });
    return data.content[0].text;
  }
}

console.log("🎉 你的 Claude Code 已经能跑了！");

```
