# Day 17: 任务拆解：把大任务变小步骤

## 这一节要解决什么问题？

"帮我做一个博客系统"——这是一个巨大的任务，AI 如果直接开始做，可能会一团糟。任务拆解：让 AI 先把大任务分成小步骤，然后一步一步完成。

## 代码演示

```js
class TaskManager {
  constructor() {
    this.tasks = [];
    this.currentIndex = 0;
  }

  // 添加任务
  add(description, subtasks = []) {
    this.tasks.push({ description, subtasks, status: "pending" });
  }

  // 获取下一个任务
  next() {
    if (this.currentIndex >= this.tasks.length) {
      return null;
    }
    return this.tasks[this.currentIndex++];
  }

  // 标记完成
  complete(taskIndex) {
    if (taskIndex < this.tasks.length) {
      this.tasks[taskIndex].status = "done";
    }
  }

  // 显示进度
  progress() {
    const done = this.tasks.filter(t => t.status === "done").length;
    return `${done}/${this.tasks.length} 任务完成`;
  }

  // 让 AI 拆解任务
  async planWithAI(userTask, client) {
    const prompt = `把以下任务拆解成 3-7 个具体步骤，每步用一句话描述：

任务：${userTask}

格式示例：
1. 第一步
2. 第二步
...

只返回步骤列表，不要其他文字。`;

    const response = await client.messages.create({
      model: "claude-sonnet-4-7-20250514",
      max_tokens: 500,
      messages: [{ role: "user", content: prompt }],
    });

    const text = response.content[0].text;
    const steps = text.split("\n").filter(line => /^\d+\./.test(line.trim()));

    for (const step of steps) {
      this.add(step.replace(/^\d+\.\s*/, ""));
    }

    return steps;
  }
}

// 测试（不需要真实 API）
const manager = new TaskManager();
manager.add("创建项目目录结构", ["src/", "tests/", "README.md"]);
manager.add("实现核心逻辑");
manager.add("编写测试用例");

let task;
while ((task = manager.next()) !== null) {
  console.log("→ 执行:", task.description);
  manager.complete(manager.currentIndex - 1);
}
console.log("✅", manager.progress());
```
