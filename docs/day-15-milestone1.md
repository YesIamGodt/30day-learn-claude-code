# Day 15: 里程碑一 — 最小可用 CLI

## 目标

恭喜你完成了 Claude Code 基础篇！今天我们将整合前 14 天的代码，构建一个**最小可用的 CLI Agent**。

## 里程碑验收清单

完成以下验收标准，说明你已经掌握了 Claude Code 的核心架构：

- [ ] 可以通过命令行参数启动
- [ ] 能发送消息并收到 AI 回复
- [ ] 能调用 BashTool（执行命令）
- [ ] 能调用 FileReadTool 和 FileWriteTool
- [ ] 有 REPL 交互界面（/help、/exit、/clear 命令）
- [ ] 有 Token 计数和成本显示
- [ ] 有上下文管理（当前目录、git 状态）
- [ ] 有权限系统（危险命令提示）
- [ ] 有配置管理（YAML 配置文件）

## 运行示例

```bash
# 安装依赖
pip install -r requirements.txt

# 设置 API Key
export ANTHROPIC_API_KEY=sk-ant-xxxxx

# 运行
python src/day-15/main.py "帮我写一个 hello world 程序"

# 进入 REPL 模式
python src/day-15/main.py --repl
```

## 架构总结

```
+-------------------------------------------------------------+
|                         REPL                                |
|     (用户输入 -> /help /exit /clear /cost)                 |
+---------------------------+---------------------------------+
                            |
+---------------------------▼---------------------------------+
|                       QueryEngine                           |
|       (工具调用循环: step -> execute -> loop)               |
+---------------------------+---------------------------------+
                            |
+---------------------------▼---------------------------------+
|              ToolRegistry -> Bash/File/Search               |
+-------------------------------------------------------------+
                            |
+---------------------------▼---------------------------------+
|                     Anthropic API                          |
+-------------------------------------------------------------+
```
